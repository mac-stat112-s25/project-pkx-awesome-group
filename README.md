# The rise and fall of democratic states: An exploration of democratic regimes prevalence since the mid-20th century

This GitHUb repository studies the democratic changes in Commonwealth countries. First, we show the number of Commonwealth
countries in 1950 and 2020. Then, by presenting the political changes in Commonwealth countries during this period, we are 
able to understand the democratization process of these countries.

In order to successfully run this GitHUb repository, you need at least version 4.4.2 of R.

Follow steps is important to successfully run this GitHUb repository. First you need to have the commonwealth countries
in 1950, then you should have the map of commonwealth countries of 1950. Second youcan get the commonwealth countries
in 2020, then you should get the map of commonwealth countries of 2020. After that you will have the different portion 
of democory election in these countries.
